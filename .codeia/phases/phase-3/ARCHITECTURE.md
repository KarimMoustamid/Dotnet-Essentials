# Phase 3 Architecture — Backend API Endpoints

Phase 3 implements a minimal API architecture where Program.cs bootstraps the app, configures SQLite via GameStoreContext, and maps two route groups (Games and Genres). Each group delegates to dedicated endpoint classes (CreateGame, GetGame, GetGames, UpdateGame, DeleteGame, GetGenres) that handle CRUD operations using DTOs and the injected database context. The endpoints reference a shared constant for route naming and leverage data annotations for input validation.
